常见安装与使用疑问

遇到问题？这里有你需要的快速指引

help_outline

如何确认我的 Mac 属于 Apple Silicon 还是 Intel？

点击屏幕左上角苹果图标 () > 选择「关于本机」。若「芯片」处标注为 Apple M1/M2/M3/M4 系列，请选择 Apple Silicon 原生版；若显示为「处理器：Intel Core」，请下载 Intel 架构版本。

admin_panel_settings

提示“无法打开，因为无法验证开发者”怎么办？

当前安装包为本地签名（ad-hoc），尚未走 Apple 公证流程。首次打开若被系统拦截，可打开 macOS「系统设置」>「隐私与安全性」，滑到底部点击「仍要打开」，或在访达中右键点击应用选择「打开」即可。

privacy_tip

应用运行时是否会向服务器上传我的视频数据？

绝不。TokPure 的所有视频解析、模型重构以及音频提取动作均完全运行在您的 Mac 本地芯片核心上，零云端中转存储，具备完全的离线断网处理能力。

record_voice_over

「AI 视频翻译」是怎么换声的？会上传我的声音吗？

不会上传。声音样本只在本机处理：客户端去掉首尾静音、做 80Hz 高通 / 9.5kHz 低通与两级频域降噪，只保留约 12 秒音色条件交给本地 Chatterbox 克隆引擎；识别（Whisper）、翻译（Llama.cpp）、配音与混音全部离线完成，成片只有一条音轨。同一段声音可以存成多个档案随时切换，出片前可以先试听。

devices_other

是否支持 Windows 平台？

支持。自 v2.4.0 起提供 Windows 11 / Windows 10 (21H2) x64 原生客户端；v3.9.27 起 Windows 版 AI 能力与 macOS 完全对齐：AI 字幕、AI 多语切片、AI 多语口播（含逐句口型对齐与本地声音克隆）、AI 视频翻译（上传自己的声音做克隆、把原片人声整条换成「你的声音说目标语言」）。原声克隆与口型引擎共用本地 Python 环境，需本机已装 Python 3.9–3.13，首次使用时客户端会自动创建虚拟环境并安装依赖（约 2GB，仅一次）。Linux 版本仍在评估中。

movie_filter

Windows 版需要自己安装 FFmpeg 或其它依赖吗？

不需要。Windows 安装包已内置完整的本地 FFmpeg 引擎，去水印与 MP3 提取开箱即用，无需额外下载或配置环境变量。
