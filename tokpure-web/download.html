Release Channel: Stable
v3.9.42 稳定版 当前版本
2026 年 11 月发布
  • auto_fix_high 彻底清除「呲呲呲」噪音块： 逐帧比对成片与频谱后确认，残留噪音不是整片底噪，而是克隆引擎在停顿处吐出的 0.5~2 秒「平稳噪声块」——频谱是一条没有谐波的宽带噪声带，电平只比说话低 6~12dB，所以按电平设的降噪门限全部放行。现在改为三条判据同时成立才处理：0.4 秒内电平波动小于 3.2dB、归一化自相关峰低于 0.42（人声实测不低于 0.50）、且前后 0.25 秒内存在 10dB 以上的停顿凹陷。命中时长整段拉到数字静音并做 11.6ms 斜坡。以问题成片为例，4 段共 5.1 秒噪音被精确清除，而全部语音帧逐样本保持不变（已验证非噪音区能量变化 0.0000dB）。
  • album 配音纯粹度复核： 重新测量成片的词间底噪，实测已全部为数字静音（20 分位 -300dB），比真人参考音（-36dB）更干净；4.5k~9k 频段与真人参考的差异仍在 ±1.5dB 内，因此本次不再改动任何 EQ 与压缩参数，避免为了「听起来亮」而再次引入齿音。
  • article 回归测试： 新增平稳噪声块检测的单元测试（合成「语音 + 静音 + 噪声块 + 静音 + 语音」信号，断言噪声块被整段检出、语音区零覆盖），并校验三条判据的标定值不可被误改。
v3.9.41 稳定版
2026 年 11 月发布
  • auto_fix_high 消除句间「呲呲」底噪： 定位到噪音并非来自配音引擎，而是人声分离后残留的立体声伴奏床被混进成片（停顿处实测约 -44~-47dB，且侧声道非零）。现在分离结果只做一次降噪并落盘复用，混音阶段不再二次处理；伴奏残渣的电平门槛从 -38 LUFS 收紧到 -31 LUFS，低于该值的分离结果直接判定为噪音并丢弃；伴奏高通从 60Hz 提到 90Hz，去掉最容易听成「嗡嗡+呲呲」的低频残渣。纯净配音链路的底噪实测已在 -60dB 以下。
  • album 配音清晰度与真人感对齐： 用真实用户音色做 1/3 倍频带对比后发现，克隆原声的高频已与真人基本齐平，旧版 +8dB / +4dB 的高频补偿会把 4.5k~9k 抬升 3~5dB，听感上就是「刺、呲、齿音重」。现改为 6.2kHz 轻度衰减 + 5.2kHz +3dB / 8.5kHz +0.5dB，各频段与真人差异收敛到 ±1.5dB 内；同时把克隆合成的采样温度固定为 0.7，降低逐句音色与气口的漂移，整片更像同一个人连续说话。
  • forum 修复偶发漏读文本： 配音引擎有时会在句子没读完时提前收尾，而时长看起来正常，旧版无法察觉；另一种情况是译文过长、语速已到上限后被画面时长静默裁掉句尾。现在每段合成完都会用本地识别引擎回读校验，字词覆盖率低于 72% 时先按更长的 token 预算重合成，仍不足则按标点拆句逐句重合成再拼接；语速上限从 1.35 提到 1.5，若译文仍超出画面长度会在任务里明确提示「片尾已裁剪」，不再无声丢内容。
  • speed 合成参数更稳： 克隆引擎默认 16 步采样、引导权重 0.3，配合固定温度 0.7，在保真与速度之间取得更好平衡，长句也不易出现音色跳变或尾音发虚。

常见安装与使用疑问

遇到问题？这里有你需要的快速指引

help_outline

如何确认我的 Mac 属于 Apple Silicon 还是 Intel？

点击屏幕左上角苹果图标 () > 选择「关于本机」。若「芯片」处标注为 Apple M1/M2/M3/M4 系列，请选择 Apple Silicon 原生版；若显示为「处理器：Intel Core」，请下载 Intel 架构版本。

admin_panel_settings

提示“无法打开，因为无法验证开发者”怎么办？

当前安装包为本地签名（ad-hoc），尚未走 Apple 公证流程。首次打开若被系统拦截，可打开 macOS「系统设置」>「隐私与安全性」，滑到底部点击「仍要打开」，或在访达中右键点击应用选择「打开」即可。

privacy_tip

应用运行时是否会向服务器上传我的视频数据？

绝不。TokPure 的所有视频解析、模型重构以及音频提取动作均完全运行在您的 Mac 本地芯片核心上，零云端中转存储，具备完全的离线断网处理能力。

forum

「AI 视频翻译」是怎么换声的？会上传我的声音吗？

不会上传。声音样本只在本机处理：客户端去掉首尾静音、做 80Hz 高通 / 9.5kHz 低通与两级频域降噪，只保留约 12 秒音色条件交给本地 Chatterbox 克隆引擎；识别（Whisper）、翻译（Llama.cpp）、配音与混音全部离线完成，成片只有一条音轨。同一段声音可以存成多个档案随时切换，出片前可以先试听。

devices_other

是否支持 Windows 平台？

支持。自 v2.4.0 起提供 Windows 11 / Windows 10 (21H2) x64 原生客户端；v3.9.27 起 Windows 版 AI 能力与 macOS 完全对齐：AI 字幕、AI 多语切片、AI 多语口播（含逐句口型对齐与本地声音克隆）、AI 视频翻译（上传自己的声音做克隆、把原片人声整条换成「你的声音说目标语言」）。原声克隆与口型引擎共用本地 Python 环境，需本机已装 Python 3.9–3.13，首次使用时客户端会自动创建虚拟环境并安装依赖（约 2GB，仅一次）。v3.9.38 起 Windows 与 macOS 共用同一套 Pro 订阅校验与付费墙，Pro 专属的 AI 视频翻译、多语切片、多语口播、批量切片、画质增强两端一致。Linux 版本仍在评估中。

movie_filter

Windows 版需要自己安装 FFmpeg 或其它依赖吗？
